# Orbit — Planet Explorer (TS Academy Frontend Capstone)

A responsive solar-system planet explorer built with semantic HTML5, CSS3 and vanilla JavaScript. It includes planet selection, a light/dark theme switcher, and live planetary measurements retrieved with the Fetch API.

## Features
- Eight-planet navigation and detail view
- Fetch API integration with Solar System OpenData (`https://api.le-systeme-solaire.net/rest/bodies/?filter=isPlanet,eq,true`)
- Loading/failure handling with local reference-data fallback
- Light and dark themes (preference saved in local storage)
- Responsive desktop and mobile layouts
- Semantic HTML and accessible labels

## Run locally
1. Download or clone this repository.
2. Open the folder in VS Code.
3. Run `index.html` with Live Server, or serve the folder with any local static server.
4. Internet access is needed for live API data and Google Fonts. The app still displays built-in reference data if the API is unavailable.

## Deployment
Deploy the repository as a static site using Netlify, Vercel or GitHub Pages. The root directory contains `index.html`.
